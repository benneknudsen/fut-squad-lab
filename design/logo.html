FUT Squad Lab

SBC Solver · Local · MIT

A squad-building solver that runs inside the FC 27 Ultimate Team web app. It spends the club's cheapest usable cards first, explains every pick, lets you swap any one player, and tells you exactly which cards you still have to buy. The mark has to work as a toolbar icon a few pixels wide and as a signature on a public repo — nothing more.

01 / the mark

One idea, drawn once

A card with a cut corner, holding a squad. The card is what this product actually manipulates — the club is a pile of them. The formation is what it builds. The chamfer is the corner the solver did not spend: the fodder it kept.

Drawn, not assembled

The card is an outline and the formation is solid, so the visual weight sits on the squad rather than the container. Nodes and links are one shape unioned by winding, not shapes stacked and hoped for: the mark stays crisp at any size and has no seam where a connector meets a node.

No crest, badge, club mark, league mark, kit or player likeness appears anywhere in the set — the project is public, unofficial, and ships under MIT. The card is a generic collectible silhouette, and the shape is ours.

Sizes

104 / 48 / 24 px — logo-mark.svg 16 px — logo-mark-16.svg

The master holds from 20 px up. Below that the outline lands under a pixel and the connectors thicken into a blob, so the 16 px cut is drawn again heavier: outline 2.6 instead of 1.9, three nodes instead of four, connectors up to 2.4. Same idea, re-cut — a scaled-down master is not an icon.

02 / construction

Everything sits on the grid

The mark is drawn on a 32-unit grid. The card is 24.8 units across, leaving 3.6 units of clear space already built into every file. The chamfer is a true 45° cut — the one diagonal in the system — and the formation is centred in the card at optical, not mathematical, centre.

03 / lockups

Three, and no more

The wordmark is set in the panel's heading treatment: uppercase, 600 weight, 0.12 em tracking, with the tagline in mono caps at 0.55 opacity — the same voice as every micro label in the app. Set the name in one weight; leave the mark to carry the colour.

Clear space

The dashed box around each lockup is the field the files already reserve — 3.6 grid units, or 11% of the icon box. Nothing is placed inside it: no type, no rules, no second logo. Nothing enters the chamfer, either.

Never rebuild it

Place the SVG as a file. Do not retype the wordmark, redraw the card in CSS, or set the name in another weight — the tracking and the mark's gap are tuned to each other.

04 / app icon

The 16 px test

The bare mark assumes a surface we control. The toolbar does not: it is near-white in light mode and near-black in dark mode. So the icon is the mark on its own tile — the card filled with surface-0, the formation in the accent, and a rim light that keeps the tile from disappearing into a dark toolbar.

06 / misuse

What breaks it

Six ways to spend the mark badly. Each one is something a real implementation does by accident, not a strawman: gradients from a hero rule, a tinted variant from a sub-brand folder, a rounded container from a card component.

No gradient. The mark is one colour plus the surface. A gradient turns a tools icon into a logo for a crypto exchange.
No stretching. The card is 24.8 units, always. A stretched card breaks the 45° chamfer that makes it a card.
No rotation, no tilt. The chamfer is the idea; rotating it makes the cut look like a mistake. Only the horizontal baseline.
No semantic recolouring. Green is the untradeable state, amber the duplicate, red the error. The mark is never a status colour.
favicon 16
No favicon shortcuts. The 16 px cut is not the master. Use it only where 16 px is the actual target; never as the default asset.
No crest, badge or club device. A shield, a ribbon, a lion, a kit number, a real player — none of it. The project is unofficial and public.

Hex, not oklch(), because rasterisers and GitHub's SVG sanitiser do not read CSS custom properties. If a token moves, these three values move with it — they are the only hard-coded colours in the set, and nothing else in the artwork is coloured at all.
